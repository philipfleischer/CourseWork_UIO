# CourseWork_UIO

A collection of coursework, assignments, exercises, and project files from my studies in Informatics at the University of Oslo (UiO).

This repository contains material from several semesters, including local coursework, IN1000/IN2000-related projects, and files from my UiO/IFI remote environment.

⸻

## Overview

The repository is organized as a long-term archive of programming and computer science coursework.

It includes:
- Semester-based coursework
- Programming assignments
- Exam preparation
- IN1000 and IN2000 material
- Android/Kotlin projects
- Python exercises
- Files from UiO/IFI remote machines
- Notes, experiments, and learning material from different courses
